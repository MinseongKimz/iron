# 프론트엔드 통계 및 분석 (Frontend Stats)

## 1. 개요
사용자의 운동 데이터를 시각화하여 성장을 확인할 수 있는 분석 페이지(`stats/page.tsx`)를 구현했습니다.

## 2. 주요 기능 (Beta)
- **주간 총 볼륨 (Weekly Volume)**
  - 최근 7일간의 총 운동 볼륨을 CSS기반의 막대 그래프(Bar Chart)로 표시합니다.
  - 최대값을 기준으로 높이를 상대값(%)으로 계산하여 렌더링합니다.
  
- **1RM 추이 (Trend)**
  - 종목별 1RM 변화를 확인할 수 있는 섹션입니다.
  - 현재는 데이터 부족 시 표시될 Placeholder UI만 구현되어 있습니다.

- **부위별 비중 (Muscle Balance)**
  - 상/하체 밸런스 등을 확인할 수 있는 Progress Bar 형태의 차트입니다.
  - 불균형이 감지될 경우(예: 하체 비중 10% 미만) 경고 카드를 표시합니다.

## 3. 기술적 특징
- 외부 차트 라이브러리(Chart.js 등) 없이 **Pure CSS/Tailwind** 만으로 가벼운 차트를 구현하여 성능을 최적화했습니다.
