# 프론트엔드 채팅 및 카드 구현 (Frontend Chat & Card)

## 1. 개요
Iron Secretaty의 핵심 기능인 'Iron Chat' 인터페이스를 구현했습니다.
사용자가 자연어로 운동 기록을 입력하면, AI가 분석한 결과를 카드 형태로 보여줍니다.

## 2. 주요 컴포넌트

### `WorkoutCard.tsx`
- AI 분석 결과를 시각화하는 컴포넌트입니다.
- **기능**:
  - 운동 요약(Summary) 표시.
  - 종목별 세트 리스트(무게, 횟수) 테이블 표시.
  - 수정/삭제 버튼 제공 (기능 미구현).
- **스타일**: Primary Color(Neon Green)를 포인트로 사용하여 분석 완료 상태를 강조.

### `chat/page.tsx`
- 채팅 인터페이스 페이지입니다.
- **구조**:
  - **Header**: 페이지 타이틀.
  - **Message List**: 대화 내용이 스크롤 가능한 영역에 표시됩니다.
    - AI 응답에 `data` 필드가 있으면 `WorkoutCard`를 렌더링합니다.
  - **Input Area**: 하단 고정된 텍스트 입력창. `Enter` 키로 전송 가능.
- **Mocking**: 현재는 백엔드 연동 전이라, 입력 시 1초 후 가상의 데이터(벤치프레스 5세트)를 응답하도록 하드코딩 되어 있습니다.

## 3. 향후 계획
